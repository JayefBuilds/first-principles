# Curriculum

Each session is designed to stand alone. Work through them in order for the full progression from an agent's basic loop to enforceable controls.

| Session | Focus | What you will practice |
|---|---|---|
| [0.1 It Has Hands Now](sessions/01-it-has-hands-now/README.md) | The agent loop and evidence from tools | Follow one real agent run and check a claim against a test. |
| [0.2 The Window Is a Budget](sessions/02-the-window-is-a-budget/README.md) | Working context has limits | Compare reading a full log with returning a focused summary. |
| [0.3 The File It Reads Before You Speak](sessions/03-the-file-it-reads-before-you-speak/README.md) | Project instructions | Test a small `AGENTS.md` or `CLAUDE.md` rule in a fresh session. |
| [0.4 Skills: A Saved Way of Working](sessions/04-skills-a-saved-way-of-working/README.md) | Reusable procedures | Apply a saved triage procedure to two bug reports. |
| [0.5 What to Hand the Agent](sessions/05-what-to-hand-the-agent/README.md) | Delegation and verification | Give the agent a bounded reading task and check a cited claim. |
| [0.6 Tools, CLIs, and MCP](sessions/06-tools-clis-and-mcp/README.md) | Tool surface area | Compare two local tool contracts without connecting to a service. |
| [0.7 Guardrails, Hooks, and Enforcement](sessions/07-guardrails-hooks-and-enforcement/README.md) | Deterministic checks | Run a portable policy check and see it catch a deliberate change. |
